# Browser Agent

### This is a browser agent which performs actions according to your prompt.

## Installation

To install dependencies for the project, run:

```bash
npm i
```

## Versions

- **ChaiAgent**  
  - Handles the signup assignment properly.  
  - But it is **hardcoded and spoon-fed with commands**.  

- **Agent-v4**  
  - Acts more like a **real browser agent** (general-purpose).  
  - May **hallucinate a bit**, but is safer and more flexible to try.  

## Usage

1. Create a `.env` file with your API key.  
2. Run either version:

```bash
node agent-v4.js
# or
node chaiAgent.js
```
